# Pour / Contre

Application web (PWA) pour poser les points négatifs, neutres et positifs d'un projet, y répondre, et faire migrer un point vers une autre colonne. Import/export JSON.

**Déploiement sur GitHub Pages** : pousser le contenu de ce dossier à la racine d'un dépôt, puis Settings → Pages → choisir la branche (dossier `/root`). Les icônes dans `icons/` sont des placeholders à remplacer si besoin.
